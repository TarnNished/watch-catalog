# Maison Horologe — Watch Catalog

A one-page catalog of pre-owned luxury watches.

**To view:** download the repo (Code → Download ZIP), unzip it, and open `index.html` in a browser.

**To edit watches:** open `index.html` and change the `WATCHES` list near the bottom (look for `EDIT YOUR WATCHES HERE`). Photos go in `images/`.

Photos are AI-generated mockups. Replace them with real photos before selling.
